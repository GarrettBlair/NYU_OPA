1. Data Repository

  • Dryad repository: Data supporting our 2023 paper on hippocampal changes during aversive learning and extinction.

2. Projects I like

  • CaImAn: a python library for large scale calcium imaging data analysis.
  • Pynapple: a light-weight python library for neurophysiological data analysis.
  • NEMOS: (Neural ModelS) is a statistical modeling framework optimized for systems neuroscience.
  • NWB Guide: Resources for using the Neurodata Without Borders (NWB) data format.
  • DANDI Archive: DANDI data archive for neuroscience data.
  • Seaborn: python visualization library based on matplotlib.
